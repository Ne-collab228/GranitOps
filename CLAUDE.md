# Операция «Гранит» — мобильный тактический шутер (Godot 4.7.2)

Оригинальный шутер от первого лица в жанре Delta Force. **Нужен только APK для Android**, ПК-версия не нужна
(клавиатура и мышь оставлены лишь для проверки). Целевой минимум — MTK Helio G81 Ultra (Mali-G52 MC2, arm64).
Лимит на всё — 1,5 ГБ (сейчас APK 132 МБ). Интерфейс и общение с пользователем — на русском.

## Команды

Ниже `G` — путь к консольному exe Godot, запуск из корня проекта.

```bash
G --headless --path . --import                 # после новых файлов/скриптов: регистрация классов, проверка ошибок
G --headless --path . -- --bake                # перезапечь навигацию (нужно после ЛЮБОЙ правки геометрии уровня)
G --path . --rendering-method gl_compatibility --resolution 960x540 --position 20,40 -- --test --touch --preset=0
                                               # автотест геймплея, скриншоты test_*.png в %APPDATA%\GranitOps
G --path . --rendering-method gl_compatibility --resolution 960x540 -- --touchtest --touch
                                               # имитация касаний: джойстик, свайп, кнопки, пауза
build_apk.bat                                  # release-сборка build/GranitOps-arm64.apk
```

Аргументы после `--`: `--play` (сразу в миссию), `--touch` (сенсорный интерфейс на ПК), `--preset=0..3`
(принудительный пресет графики), `--perf` (раз в секунду печатает fps, вызовы отрисовки, треугольники).
Всегда тестировать с `--rendering-method gl_compatibility`: на телефоне работает именно этот рендер.

Универсальный APK: `--export-release "Android" build/GranitOps.apk` с теми же переменными окружения
`GODOT_ANDROID_KEYSTORE_RELEASE_*`, что в `build_apk.bat`.

Окно теста появляется на экране пользователя — держать его маленьким. Если он в это время играет в другую
игру, FPS на ПК ничего не значит, а перетаскивание окна подвешивает тест.

### Linux-контейнер

Godot (`godot` в PATH или `$GODOT`), JDK 17 и Android SDK (`/opt/granit-tools`) уже стоят в образе; пути для экспорта —
в `~/.config/godot/editor_settings-4.7.tres`. Окна нет — тесты идут в виртуальном X-сервере с программным GL (медленно:
FPS ничего не значит, автотест `--test` занимает больше 8 минут — запускать с `timeout` и в фоне).

```bash
bash tools/setup_linux.sh  # один раз: Godot, шаблоны Android, JDK 17, SDK, xvfb + mesa (идемпотентно)
godot --headless --path . --import              # первый запуск в новой копии
sh tools/check.sh          # компиляция скриптов; код 1 и список ошибок при SCRIPT ERROR/Parse Error — запускать перед run_x.sh
tools/run_x.sh --path . --resolution 960x540 -- --test --touch --preset=0   # тест с окном; скриншоты ~/.local/share/GranitOps/test_*.png
godot --headless --path . --export-debug "Android arm64" /tmp/x.apk         # отладочный APK (подпись debug.keystore из настроек)
```

Из экспорта исключены `tools/*`, превью-сцены, `assets/vehicles/src/*`, `*.md`, `*.txt` (`exclude_filter` в `export_presets.cfg`) —
новые вспомогательные сцены и исходники моделей добавлять туда же. Скрипты на `res://tools` в игре не грузятся.

## Архитектура

Сцена одна (`scenes/main.tscn`, пустой узел со `scripts/main.gd`). **Всё строится кодом**, редактор не нужен.

| Файл | Назначение |
|---|---|
| `settings.gd` (автозагрузка Settings) | Пресеты графики, автоопределение по GPU, динамическое разрешение, сохранение в `user://settings.cfg` |
| `sfx.gd` (Sfx) | Пул звуков, задержка по скорости звука |
| `game.gd` (Game) | Реестр (player, level, fx, enemies…), карта ввода, статистика, `Game.noise()` |
| `main.gd` | Загрузка, меню, старт/пауза/рестарт, автотесты |
| `level.gd` | Рельеф, база, блокпост, РЛС, точка эвакуации, растительность, список врагов, навигация |
| `geo.gd` | Сборщик геометрии: коробки/цилиндры/стены/лестницы в один меш на материал + коллизии по типу поверхности |
| `mats.gd` | Материалы (ORM из текстур Poly Haven), материалы оружия от первого лица |
| `terrain.gdshader` | Смешивание слоёв рельефа по цвету вершин |
| `soldier_rig.gd`, `enemy.gd` | Скиннутый солдат (1 draw call) и ИИ: зрение, слух, тревога, укрытия, стрельба |
| `ballistics.gd` | Пули-снаряды: гравитация, сопротивление, пробитие `wood`/`sheet`, свист рядом с игроком |
| `fx.gd`, `grenade.gd` | Пулы частиц, декали, вспышки, взрывы, огонь |
| `gun_models.gd`, `weapons.gd` | Модели и логика оружия: отдача, разброс, перезарядка, анимация |
| `player.gd` | Движение, камера, здоровье, ввод (сенсор, клавиатура, геймпад), помощь в прицеливании |
| `hud.gd`, `touch.gd`, `menu.gd` | Интерфейс боя, сенсорные кнопки, меню и настройки |
| `mission.gd` | Задачи, заряды, пополнение боезапаса, эвакуация |

Ключевые решения:
- Рендер: `gl_compatibility` на телефоне, `forward_plus` на ПК. Выбор Vulkan на телефоне — через `user://override.cfg`.
- Игрок двигается в `_process` (плавно при любой частоте кадров), у него физическая интерполяция выключена;
  враги двигаются в `_physics_process` и интерполируются.
- Координаты: север = −Z, восток = +X. Земля базы на высоте `Level.H0 = 2.0`.
- Тип поверхности хранится в метаданных тела `surf`: `dirt`, `concrete`, `metal`, `wood`, `sheet` (два последних простреливаются).
- Слои физики: 1 мир, 2 игрок, 4 враги, 8 динамика.

## Ассеты

- `assets/tex`, `assets/models`, `assets/sky` — CC0 с Poly Haven, качаются `tools/fetch_assets.py <путь к проекту>`.
- `assets/gen` (камуфляж, декали, вспышки, трава) и `assets/sfx` (все звуки синтезированы) — `tools/gen_assets.py <путь>`.
  Этот же скрипт пишет `.import` для всех текстур (VRAM-сжатие + мипмапы). Без этих `.import` текстуры
  импортируются без сжатия и мипмапов.
- `tools/sun.gd` — находит направление на солнце в HDRI (значение зашито в `Level.SUN_DIR`).
- `tools/remote_zip.py` — достаёт отдельные файлы из удалённого zip (так скачаны только Android-шаблоны).
- Python: запускать `python -I`, есть numpy, PIL, scipy.

Особенности моделей: стволы винтовки и пистолета смотрят в +X (поворот на 90° вокруг Y);
`steel_frame_shelves_01` в 10 раз больше нормы (масштаб 0.1); `old_tyre` стоит вертикально.

## Грабли GDScript, на которые уже наступали

- `var x := ...` не выводит тип из Variant (элемент массива/словаря, нетипизированная переменная) — писать тип явно.
- `min/max/clamp/lerp/abs` возвращают Variant — использовать `minf/maxf/clampf/lerpf/absf`.
- Нельзя называть метод `_set` (конфликт с `Object._set`) и переменную `tan`.
- Многострочная лямбда допустима только последним аргументом вызова.
- В шрифте по умолчанию нет символов вроде ✔ ✚ ● — в интерфейсе только буквы и обычная пунктуация.
- Передние грани в Godot — по часовой стрелке; в `geo.gd` это учтено, при новой геометрии использовать `Geo.tri`.

## Что стоит сделать дальше

1. Получить от пользователя FPS на телефоне (счётчик включается в настройках) и отзывы об управлении.
2. Если FPS мало: с видом на базу сейчас ~400–450 вызовов отрисовки и ~160 тыс. треугольников даже на низком
   пресете. Рычаги: дальность видимости мелких объектов (`visibility_range_end` в `Level.apply_quality`),
   упрощённый меш солдата на дистанции, объединение многочастных моделей, меньше камней.
3. Солдаты и автомат собраны из примитивов и выглядят угловато — заменить на нормальные модели с анимациями.
4. Звуки синтетические, голосов нет. Миссия одна. Перезапуск миссии заново строит весь уровень.
5. Пройти миссию до конца и проверить итоговый экран.
